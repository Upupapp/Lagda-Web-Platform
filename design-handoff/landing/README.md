# LAGDA landing page — handoff for Claude Code

1. Unzip this folder into the root of the Lagda-Web-Platform repo and rename it to `design-handoff/landing/`
   (so the reference file is at `design-handoff/landing/reference/index.html`).
2. Open the repo in VS Code and start Claude Code.
3. Paste this one line:

   > Read `design-handoff/landing/CLAUDE_CODE_PROMPT.md` and do exactly what it says. Start by opening `design-handoff/landing/reference/index.html` and the screenshots.

4. When it finishes, review the side-by-side screenshots it reports before merging.

What's inside:

- `reference/index.html` — the approved page, exactly as published.
- `reference/img/` — all photos, logos and app screenshots the page uses.
- `reference/screenshots/` — how it must look at desktop (1440 px) and mobile (390 px).
- `CLAUDE_CODE_PROMPT.md` — the full instructions, including where every button and link goes.
